API reference¶

All public functions are importable from the top-level niizarr package.

Conversion¶

nii2zarr ¶

nii2zarr(
    inp: Union[Nifti1Image, Nifti2Image, Any],
    out: Union[str, Any],
    *,
    chunk: Union[int, Tuple[int]] = 64,
    chunk_channel: int = 1,
    chunk_time: int = 1,
    shard: Optional[Union[int, Tuple[int]]] = None,
    shard_channel: Optional[int] = None,
    shard_time: Optional[int] = None,
    nb_levels: int = -1,
    method: Literal["gaussian", "laplacian"] = "gaussian",
    label: Optional[bool] = None,
    no_time: bool = False,
    no_pyramid_axis: Optional[Union[str, int]] = None,
    fill_value: Optional[Union[int, float, complex]] = None,
    compressor: Literal["blosc", "zlib"] = "blosc",
    compressor_options: dict = {},
    zarr_version: Literal[3] = 3,
    ome_version: Literal["auto", "0.5", "0.6"] = "auto",
    validate: bool = False,
) -> None

Convert a nifti file to nifti-zarr.

Parameters:

Name Type Description Default
inp Nifti1Image | Nifti12mage | file - like

Input nifti image.

 required
out (Store, Group or path)

Output zarr object/path. If object, it must be opened with "w" capability.

 required
chunk int or tuple of int

Chunk size for spatial dimensions. The tuple allows different chunk sizes to be used along each dimension.

 64
chunk_channel int

Chunk size of the channel dimension. If 0, combine all channels in a single chunk.

 1
chunk_time int

Chunk size for the time dimension. If 0, combine all timepoints in a single chunk.

 1
shard int or tuple of int

Shard size for spatial dimensions. The tuple allows different shard sizes to be used along each dimension.

 None
shard_channel int

Shard size of the channel dimension. If 0, combine all channels in a single shard.

 None
shard_time int

Shard size for the time dimension. If 0, combine all timepoints in a single shard.

 None
nb_levels int

Number of pyramid levels to generate. If -1, make all possible levels until the level can be fit into one chunk.

 -1
method (gaussian, laplacian)

Method used to compute the pyramid.

 'gaussian'
label bool

Is this is a label volume? If None, guess from intent code.

 None
no_time bool

If True, there is no time dimension so the 4th dimension (if it exists) should be interpreted as the channel dimensions.

 False
no_pyramid_axis (x, y, z)

Axis that should not be downsampled. If None, downsample across all three dimensions.

 'x'
fill_value number

Value to use for missing tiles

 None
compressor (blosc, zlib)

Compression to use

 'blosc'
compressor_options dict

Options for the compressor.

 {}
zarr_version 3

Zarr format version. Only Zarr v3 is written (v2 can still be read).

 3
ome_version (auto, 0.5, 0.6)

OME-Zarr version. Default: "auto" (currently "0.6"). Writing 0.5 will be deprecated in a future release. With 0.6, the NIfTI qform/sform spaces are described as coordinate systems.

 "auto"
validate bool

Validate the Zarr with the ome-zarr-models package.

 False

Returns:

Type Description
None

write_ome_metadata(
    omz: Group,
    axes: List[str],
    space_scale: Union[float, List[float]] = 1.0,

    space_unit: str = "micrometer",
    time_unit: str = "second",

    ] = 2,
    levels: Optional[int] = None,
    no_pool: Optional[int] = None,
    multiscales_type: str = "",
    ome_version: Literal["0.5", "0.6"] = "0.6",
) -> None

Write OME metadata into Zarr.

Parameters:

Name Type Description Default
omz Group

Zarr group to write metadata

 required
axes list[str]

Name of each dimension, in Zarr order (t, c, z, y, x)

 required
space_scale float | list[float]

Finest-level voxel size, in Zarr order (z, y, x)

 1.0
time_scale float

Time scale

 1.0
space_unit str

Unit of spatial scale (assumed identical across dimensions)

 'micrometer'
time_unit str

Unit of time scale

 'second'
name str

Name attribute

 ''
pyramid_aligns float | list[float] | {center, edge}

Whether the pyramid construction aligns the edges or the centers of the corner voxels. If a (list of) number, assume that a moving window of that size was used.

 2
levels int

Number of existing levels. Default: find out automatically.

 None
