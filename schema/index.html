JSON schema¶

The JSON variant of the NIfTI header, stored in the attributes of the nifti Zarr array (nifti/zarr.json) (see section 2.4 of the specification), is described by the JSON schema below. Its canonical location is https://github.com/neuroscales/nifti-zarr/blob/main/nifti-zarr-schema-1.0.rc1.json.
